## 1. Getting Started

### 1.1 User Roles
The system supports four user roles with different permissions:
- Super Admin: Full system access and configuration
- Leadership: Overview and approval capabilities
- Lead: Manages interventions and actions
- Supporting Staff: Assists with action implementation

### 1.2 Logging In
1. Navigate to the application URL
2. Enter your email and password
3. First-time users will be prompted to change their password

## 2. User Dashboard

### 2.1 Dashboard Overview
The dashboard displays:
- Your assigned interventions and actions
- Recent activities
- Upcoming deadlines
- Issues requiring attention

### 2.2 Filtering and Navigation
- Use status filters (all, in_progress, at_risk, completed)
- Filter by type (intervention, action)
- Use role filters to view specific assignments

## 3. Interventions Management

### 3.1 Creating an Intervention
1. Click the "+" button on the dashboard
2. Fill in required details:
   - Name
   - Description
   - Start/End dates
   - Lead assignment
   - Supporting staff

### 3.2 Managing Documents
1. Navigate to intervention details
2. Use the Documents tab
3. Upload files using the upload button
4. View or download existing documents

## 5. Issue Tracking

### 5.1 Reporting Issues
1. Navigate to the action details
2. Click "Report Issue"
3. Specify:
   - Description
   - Severity (low, medium, high, critical)
   - Is it a blocker?
   - Resolution steps (if any)

### 5.2 Managing Issues
1. View issues in the Issues Dashboard
2. Update status:
   - Open
   - In Progress
   - Resolved
3. Add resolution details when closing
4. Track impact on action status

### 5.3 High-Severity Issues
- Automatically flag associated actions as "at risk"
- Require immediate attention
- Must document resolution steps
- Need leadership review for closure

### 7.2 Managing User Access
